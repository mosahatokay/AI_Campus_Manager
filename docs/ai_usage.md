# CampusAI — נספח שימוש ב־AI לאבן דרך א׳

**מגישים:** מוסא ונוריאן (לוודא שמות מלאים) · **תקופת העבודה:** אוקטובר–נובמבר 2026 · **תאריך עדכון:** 24.11.2026

## כלי/מודל ותאריך, מטרה והנחיות מרכזיות

**ChatGPT של OpenAI** (בשיחה הנוכחית GPT-6; גרסאות מדויקות של שיחות מוקדמות לא אומתו) סייע בתכנון, כתיבת קוד Python וחוזי JSON Schema, בניית בדיקות, חיבור Mock/SQL Server, ניסוח מסמכים והסברים להרצות GitHub ו־Colab. הסיוע היה לאורך אוקטובר–נובמבר 2026. ההנחיות העיקריות: לפתח סוכן למזכירה לניהול חדרים ומבחנים; לאכוף ימי א׳–ה׳ 08:00–22:00, קיבולת/מחשבים/מקרן ואישור אנושי לפני שינוי; לשמר SQL Server מקומי אך לאפשר בדיקות מלאות ב־Mock וב־Colab ללא API בתשלום; לדווח על תוצאות אמיתיות בלבד; להפריד בין מודל מדומה למודל אמיתי.

**Qwen/Qwen2.5-0.5B-Instruct**, מודל שפה פתוח שנבדק ב־Google Colab על CPU ב־23–24.11.2026: בחר כלי `find_rooms` שהוחזר ממנו `ok`, אך בהמשך הפיק `12` במקום אובייקט JSON והתרחשה שגיאת `ValueError`/`model_unavailable`. **אין להציג זאת כהדגמת שיחה מלאה מוצלחת.** לא נדרש מודל בתשלום במסגרת בדיקות אבן דרך א׳.

## גבולות ההוכחה ואחריות

ההרצות האוטומטיות להגשה משתמשות ב־`ScriptedModel` וב־`MockBackend`: ההחלטות נקבעות מראש והנתונים סינתטיים. הן מוכיחות תקינות לולאה, אישור, מצב, כלים ותגובה לכשל — **לא** איכות הבנת שפה חופשית של מודל אמיתי. תוצאת `131 passed in 2.25s` היא **מקומית**; יש לצלם ולתעד תוצאה של Colab נקי לאחר העלאת הקוד המעודכן. אין סודות API בקבצי ההגשה. האחריות להבין, לבדוק ולאמת את קוד ה־AI היא של שני המגישים. את התרומה של נוריאן יש להשלים רק לפי מה שנעשה בפועל.
